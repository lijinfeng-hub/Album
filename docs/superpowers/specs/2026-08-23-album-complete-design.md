# Album 完整版设计规格

## 目标

把当前只有“创建项目向导 + 项目树骨架”的 Qt 相册程序，完成为一个可以日常使用的轻量桌面相册：用户能够创建或打开相册项目，导入图片，浏览和预览图片，给图片打标签，做基础编辑，播放背景音乐，并将项目状态可靠地保存下来。

本版本优先保证主流程完整、数据可移动、操作有反馈；不追求专业图片编辑器或云端能力。

## 范围与完成标准

### 必须完成

1. 项目管理
   - 创建项目目录和项目名称。
   - 打开已有项目目录或项目描述文件。
   - 关闭项目，并在项目树中显示当前已加载的项目。
   - 项目数据保存到项目目录内，项目目录移动后仍然可以打开。

2. 图片管理
   - 导入一张、多张图片或一个文件夹。
   - 支持常见格式：PNG、JPG/JPEG、BMP、GIF、WEBP（以 Qt 当前编译环境支持的格式为准）。
   - 导入时复制到项目的 `photos/` 目录，不修改用户原始文件。
   - 生成缩略图网格，显示文件名和数量。
   - 删除图片、刷新图片列表、按名称或导入时间排序。
   - 损坏或不支持的文件不能进入项目，并且要给出明确提示。

3. 预览和轮播
   - 点击缩略图打开大图预览。
   - 预览中支持上一张、下一张、适应窗口、原始尺寸。
   - 轮播支持播放/暂停、上一张、下一张、循环和间隔设置。
   - 轮播期间可以继续播放背景音乐。

4. 标签分类
   - 每张图片可以拥有多个自定义标签。
   - 可以新增、删除、重命名标签。
   - 可以按一个标签筛选图片，也可以切回全部图片。
   - 删除标签不会删除图片，只清理该标签关联。

5. 基础图片编辑
   - 顺时针/逆时针旋转 90 度。
   - 水平翻转和垂直翻转。
   - 裁剪为用户选择的矩形区域。
   - 亮度调整。
   - 灰度效果。
   - 重置编辑结果。
   - 编辑使用非破坏式数据：原始导入图片保留，编辑后的预览/导出结果单独保存。

6. 背景音乐
   - 导入本地音频文件，至少支持 Qt Multimedia 能播放的常见格式。
   - 播放/暂停、上一首、下一首、音量、循环播放。
   - 在项目中保存音乐列表，项目移动后使用相对路径。
   - 音频文件失效时跳过该文件并提示，不阻塞图片功能。

### 本版本不做

- 云同步、账号登录、网络相册。
- 人脸识别、自动分类、地图定位。
- RAW 专业处理、复杂滤镜、图层和专业色彩管理。
- 多窗口协同编辑和撤销历史栈。

## 用户流程

### 创建和打开项目

用户从“文件”菜单选择“创建项目”，选择父目录和名称。程序创建以下目录结构，并立即将项目加载到项目树：

```text
<project>/
  album.json
  photos/
  edits/
  music/
```

用户从“打开项目”选择包含 `album.json` 的目录或直接选择 `album.json`。程序读取 JSON，检查照片和音乐的相对路径，将有效记录加载到界面；缺失资源保留元数据但标记为不可用并提示。

### 导入和浏览图片

用户选择项目树中的项目后，右侧显示当前项目。点击“导入图片”可多选文件，点击“导入文件夹”可选择目录并扫描第一层图片文件。每个文件先通过 `QImageReader` 验证，随后复制到 `photos/`，生成唯一文件名，并追加一条 `PhotoRecord`。导入完成后一次性刷新缩略图列表并保存项目。

缩略图列表使用 `QListWidget` 的 IconMode 或等价的 Qt Widgets 组件，避免为每张图片创建独立窗口。当前标签筛选条件只影响显示，不会改变项目中的记录。

### 编辑和保存

用户选中一张图片点击“编辑”，编辑器加载原图和已有编辑参数。编辑操作只改变内存中的 `QImage` 和编辑状态。点击“应用”时将渲染结果写入 `edits/`，更新记录中的编辑字段并保存 JSON；点击“取消”不改项目；点击“重置”删除编辑结果并恢复原图。

### 标签筛选

用户可以对当前选中图片打开标签对话框，输入或勾选多个标签。标签名经过去空格和空值过滤，项目级标签表负责去重。右侧筛选栏显示已有标签，点击标签后由项目模型返回匹配记录，画廊只重新绑定可见项。

### 轮播和音乐

轮播使用当前筛选后的图片顺序。轮播窗口只负责显示和计时，图片顺序及音乐播放由控制器提供。音乐控制器独立于图片轮播，轮播关闭时可以选择继续播放；窗口关闭或项目关闭时停止并释放媒体资源。

## 架构

程序继续使用 Qt 6 Widgets 和 C++17，不引入第三方库。主窗口只负责组装界面和协调信号，业务状态放在可独立测试的类中。

### 数据模型

新增 `AlbumProject` 负责项目状态、筛选、排序和 JSON 持久化；`PhotoRecord` 是单张图片的元数据。项目模型不依赖具体的 QWidget。

建议的照片记录结构：

```json
{
  "id": "稳定的 UUID 字符串",
  "file": "photos/2026-08-23_001.jpg",
  "name": "原始显示名称",
  "tags": ["旅行", "夏天"],
  "importedAt": "2026-08-23T12:00:00",
  "edit": {
    "rotation": 90,
    "flipHorizontal": false,
    "flipVertical": false,
    "brightness": 0,
    "grayscale": false,
    "crop": {"x": 0, "y": 0, "width": 0, "height": 0}
  }
}
```

项目文件结构：

```json
{
  "version": 1,
  "name": "我的相册",
  "photos": [],
  "tags": ["旅行", "家人"],
  "music": ["music/background.mp3"],
  "musicLoop": true,
  "lastFilter": "全部",
  "sort": "importedAt"
}
```

写入使用 `QSaveFile`，先写临时文件再提交，避免程序中断留下半个 JSON。所有项目内路径保存为相对路径；读取时以项目目录为基准解析。

### 组件职责

| 组件 | 职责 | 不负责的内容 |
| --- | --- | --- |
| `AlbumProject` | 项目数据、照片记录、标签、排序、读写 JSON | QWidget 绘制 |
| `PhotoImporter` | 文件扫描、格式验证、复制、生成唯一名称 | 修改标签和编辑状态 |
| `PhotoGalleryWidget` | 缩略图加载、选择、删除和上下文菜单 | 项目文件写入 |
| `PhotoViewerDialog` | 单张图片预览和前后切换 | 导入和标签持久化 |
| `ImageEditorDialog` | 旋转、翻转、裁剪、亮度、灰度和预览 | 项目列表筛选 |
| `MusicController` | Qt Multimedia 播放列表、音量和循环 | 图片状态 |
| `SlideshowDialog` | 轮播计时和全屏显示 | 音乐文件扫描 |
| `MainWindow` | 菜单、工具栏、左右布局、组件连接 | 直接维护 JSON 字段 |

### 主界面布局

保留现有的深色风格和左侧项目树，调整中央布局为：

```text
┌ 菜单栏：文件 / 图片 / 查看 / 设置 ─────────────────────────────┐
├ 项目树 ─────┬ 工具栏：导入 编辑 标签 轮播 刷新 删除 ───────────┤
│ 项目列表    │ 标签筛选：全部 | 标签A | 标签B   排序             │
│             ├──────────────────────────────────────────────────┤
│             │              图片缩略图网格                       │
│             │                                                    │
├ 音乐控制 ───┴ 状态栏：图片数量 / 当前选择 / 资源提示 ───────────┤
```

右侧没有活动项目时显示空状态提示和“创建/打开项目”按钮；导入过程中使用状态栏提示，必要时使用非阻塞消息框汇总失败文件。

## 数据流和边界

```text
用户操作
  -> MainWindow
  -> AlbumProject / PhotoImporter / MusicController
  -> Qt Widgets 更新
  -> AlbumProject.save()
```

- 选择项目：`MainWindow` 调用 `AlbumProject::open()`，成功后刷新标签栏和画廊。
- 导入图片：`PhotoImporter` 返回新增 `PhotoRecord`，模型合并并保存，画廊只接收刷新后的可见记录。
- 标签筛选：模型根据 `activeTag` 返回 `filteredPhotos()`，画廊不复制业务过滤逻辑。
- 编辑图片：编辑器返回 `EditSettings` 和渲染后的 `QImage`，模型更新记录后保存。
- 音乐播放：`MusicController` 只接收项目音乐相对路径转换后的绝对路径，并通过信号报告播放状态和错误。

## 错误处理

- 项目目录不存在或不可写：创建/打开失败，说明具体路径和原因。
- `album.json` 缺失或版本不支持：拒绝打开并提示“不是有效的 Album 项目”或“项目版本过新”。
- 图片无法读取：跳过该文件，汇总文件名和原因，不中断其他导入。
- 目标文件名冲突：保留两个文件，自动追加序号，不覆盖既有照片。
- 编辑结果写入失败：保留原记录，提示用户检查磁盘空间和权限。
- 音频加载失败：移除当前播放项或标记失效，图片浏览和轮播继续工作。
- 项目关闭前若有未保存更改：询问保存、放弃或取消关闭。

## 测试策略

测试以 Qt Test 为主，优先覆盖不依赖窗口的业务类：

1. `AlbumProject`：创建目录、JSON 保存/读取、相对路径解析、标签去重、标签筛选、排序。
2. `PhotoImporter`：支持格式验证、重复文件名生成、导入失败不污染项目。
3. 编辑渲染：旋转、翻转、灰度、亮度和裁剪结果的尺寸/像素行为。
4. `MusicController`：播放列表增删、循环状态和失效文件跳过；媒体实际播放在可用环境中做轻量集成检查。
5. GUI 冒烟：无项目时空状态、创建项目后项目树出现、导入后缩略图数量正确、筛选后数量正确。

每个新增行为遵循先写失败测试、确认失败、实现最小代码、再跑全量测试的 TDD 流程。最终至少执行 Debug 构建和全部测试；如果本机 Qt Multimedia 或媒体编解码器不可用，需要把该限制写入验证结果，而不是静默跳过。

## 构建和依赖

在现有 `CMakeLists.txt` 基础上增加 Qt Multimedia：

- `find_package(Qt${QT_VERSION_MAJOR} REQUIRED COMPONENTS Widgets Multimedia Test)`（测试目标可单独查找 Test）。
- 主程序链接 `Qt${QT_VERSION_MAJOR}::Widgets` 和 `Qt${QT_VERSION_MAJOR}::Multimedia`。
- 测试目标链接 `Qt${QT_VERSION_MAJOR}::Test`、`Qt${QT_VERSION_MAJOR}::Widgets`。
- 继续使用 C++17、自动 MOC/UIC/RCC。
