# Album相册管理系统

软件简称：Album　　版本号：V1.0　　软件分类：应用软件

Album相册管理系统是一个基于 Qt 6 Widgets 的桌面相册管理软件，支持项目化保存图片、缩略图浏览、标签筛选、基础编辑、轮播和背景音乐。程序采用 C++17 开发，使用 Qt Multimedia 完成音频播放，项目数据以 JSON 和相对路径保存。

## 构建

项目使用 CMake，当前开发配置为 Qt 6.8.3 + MSVC 2022 64 位 + C++17。Windows 下请先在 Visual Studio x64 开发者命令环境中构建：

```powershell
cmake --build build/Desktop_Qt_6_8_3_MSVC2022_64bit-Debug --config Debug --parallel 2
```

运行测试：

```powershell
ctest --test-dir build/Desktop_Qt_6_8_3_MSVC2022_64bit-Debug --output-on-failure
```

如果 PowerShell 没有 `cl.exe`，请先运行 Visual Studio 的 `vcvars64.bat`，否则 MSVC 会找不到标准库头文件。

## 使用

1. 从“文件 → 创建项目”新建相册，或从“文件 → 打开项目”选择已有的 `album.json`。
2. 使用“图片 → 导入图片”选择一张或多张图片，也可以导入整个文件夹。
3. 双击缩略图预览；选择图片后可以编辑、修改标签或删除。
4. 在标签筛选栏按标签查看分类图片，并可按导入时间或文件名排序。
5. 点击“开始轮播”或项目树右键菜单中的轮播功能播放当前筛选结果。
6. 从“设置 → 导入背景音乐”添加音频，然后使用窗口底部的播放控制和音量滑块。

## 图片编辑

编辑器支持旋转 90 度、水平/垂直翻转、亮度、灰度和裁剪。编辑结果保存到 `edits/`，原始图片始终保留；点击“重置编辑”即可恢复原图。

## 项目目录

```text
相册项目/
  album.json   # 项目名称、图片元数据、标签和音乐列表
  photos/      # 导入后的原始图片
  edits/       # 编辑后的 PNG 结果
  music/       # 导入后的背景音乐
```

项目 JSON 使用相对路径，因此整个项目目录可以整体移动。原始文件不会因为导入或编辑而被修改。
